# Deals und Pipeline in der MyInvest Pro App

Dieser Abschnitt beantwortet die häufigen Fragen zum Bereich "Deals" und zur Vertriebs-Pipeline in der MyInvest Pro Software. Ein Deal steht dabei immer für eine konkrete Verkaufschance.

Wie verschieben Sie einen Deal in eine andere Phase? In der Kanban-Ansicht ziehen Sie den Deal per Drag and Drop einfach von einer Spalte in die nächste. Arbeiten Sie in der Listenansicht, klicken Sie stattdessen auf den Status-Badge des Deals und wählen dort die neue Phase aus.

Wann wird eine Provision berechnet? Provisionen werden automatisch berechnet, sobald ein Deal auf den Status "Gewonnen" gesetzt wird. Die Höhe der Berechnung ergibt sich aus dem Deal-Wert und Ihrer Karrierestufe. Solange ein Deal noch in einer früheren Phase steht, findet also keine Provisionsberechnung statt.
