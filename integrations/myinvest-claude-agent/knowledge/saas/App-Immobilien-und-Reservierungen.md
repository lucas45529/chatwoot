# Immobilien und Reservierungen in der MyInvest Pro App

Dieser Abschnitt fasst die häufigen Fragen zu Objekten und Reservierungen in der MyInvest Pro Software zusammen. Die zugehörigen Bereiche sind in der Anwendung die Objekte beziehungsweise Immobilien und die Reservierungen.

Wie reservieren Sie eine Einheit für einen Kunden? Öffnen Sie zunächst das Objekt und wählen Sie darin eine verfügbare Einheit aus. Klicken Sie dann auf "Reservieren", wählen Sie den passenden Kontakt aus und bestätigen Sie die Reservierung. Damit ist die Einheit für diesen Kunden vorgemerkt.

Wie lange ist eine Reservierung gültig? Reservierungen haben eine konfigurierbare Gültigkeitsdauer. Läuft diese Dauer ab, wird die Einheit automatisch wieder freigegeben, sofern zu diesem Zeitpunkt kein Kaufvertrag vorliegt. Wenn Sie eine Reservierung länger halten möchten, achten Sie deshalb rechtzeitig auf den weiteren Fortgang des Vorgangs.
